# LaBovedaProhibida

Proyecto de entretenimiento con temática de misterio y retos.

## Descripción

Este repositorio presenta una idea de juego o experiencia interactiva basada en la exploración de escenarios secretos y la resolución de enigmas.

## Funcionalidades

- Temática de aventura.
- Interfaz gráfica.
- Desafíos y progresión.
- Enfoque en experiencias lúdicas.

## Tecnologías

- C#
- Windows Forms
- .NET

## Ejecución

1. Abre la solución en Visual Studio.
2. Compila el proyecto.
3. Ejecuta la aplicación.
